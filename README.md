# 🛣️ Road Accident Analysis & Prediction Dashboard

An interactive dashboard analyzing road accidents across **Tamil Nadu, Kerala, and Karnataka** using historical data from **2021–2023**, with predictions for **2024–2025**. The project identifies accident patterns, high-risk districts, weather-related trends, and severity patterns to support data-driven road safety planning.

## 🎯 Business Problem

Road accidents result in significant human and economic losses. This project uses historical accident data to identify patterns and provide predictive insights that can support proactive road safety planning.

The analysis focuses on:

- Identifying high-risk districts and states
- Understanding accident trends over time
- Analyzing the relationship between weather and accidents
- Examining accident severity patterns
- Predicting future accident trends for 2024–2025

## 🔍 Approach

The project follows an end-to-end data analytics and predictive modeling workflow:

**Data Collection → Data Cleaning → Exploratory Data Analysis → Feature Engineering → Predictive Modeling → Dashboard Development → Insights → Recommendations**

### Data Analysis

- Cleaned and prepared accident data from 2021–2023
- Handled missing and inconsistent values
- Analyzed yearly, state-wise, and district-wise accident patterns
- Examined accident severity and weather conditions
- Identified high-risk districts and recurring patterns

## 🤖 Predictive Modeling

Two machine learning approaches were explored to predict accident trends for 2024–2025:

- **XGBoost**
- **LSTM**

Models were evaluated using:

- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC

## 💡 Key Insights

- Certain districts consistently recorded higher accident volumes.
- Accident patterns varied across Tamil Nadu, Kerala, and Karnataka.
- Weather conditions showed noticeable differences in accident occurrence.
- Accident severity varied across districts and weather conditions.
- Historical patterns provided a basis for forecasting accident trends for 2024–2025.

## 📌 Recommendations

Based on the analysis and predictions:

- Prioritize road safety interventions in high-risk districts.
- Strengthen preventive measures during weather conditions associated with higher accident occurrence.
- Use district-level accident patterns to support emergency response planning.
- Consider accident trends when planning road safety policies and infrastructure improvements.
- Use predictive insights to support proactive rather than reactive safety measures.

## 🚀 Future Improvements

- Incorporate traffic density, road conditions, and demographic factors.
- Explore additional forecasting and deep learning models.
- Integrate real-time traffic and accident data.
